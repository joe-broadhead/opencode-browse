# Security policy

## Reporting a vulnerability

Report a security issue privately, not in a public issue. Use GitHub's private vulnerability reporting on this
repository: **Security** → **Report a vulnerability**.

Include the version, the OpenCode release, the platform, what you ran, and what happened. Do not include a real
credential, a page's content or a person's data; a short description and a redacted log are enough.

You will get an acknowledgement within three working days. Please give us time to ship a fix before you publish.

## Supported versions

Only the latest `v0.0.x` release is supported while the plugin is pre-1.0.

## Scope

The plugin runs the pinned browse binary and, in managed mode, a pinned Chrome for Testing. A report about the browse
product itself belongs to its vendor; a report about how this plugin resolves, verifies or runs those files, or about
what it writes to status and logs, belongs here.
